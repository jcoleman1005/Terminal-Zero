================================================================================
         SYSADMIN REFERENCE GUIDE // HOW TO READ 'll' (LONG LISTING)
================================================================================
Standard 'ls' only shows visible filenames.
The 'll' shortcut reveals hidden dotfiles and prints 5 critical columns:

  [ PERMISSIONS ]  [ LINKS ]  [ OWNER ]  [ SIZE ]  [ FILENAME ]
  -rw-r--r--       1          root       4096      alice.bashrc
  drwxr-xr-x       1          root       4096      profiles/
  ----------       1          root       4096      recovery.sh

--------------------------------------------------------------------------------
DECODING THE PERMISSIONS COLUMN:
--------------------------------------------------------------------------------
• 1st character: 'd' = Directory (folder), '-' = Regular file.
• Next 3 chars : Owner permissions:
                 'r' = Read (can view contents with 'cat' or 'head')
                 'w' = Write (can edit or overwrite with '>')
                 'x' = Execute (can run programs or scripts like './tool')
                 '-' = Permission revoked / missing.

[KEY RECOVERY TAKEAWAY]:
If a tool has '---' instead of 'r-x' or 'rwx', it cannot run!
You can restore executable permissions on any file using 'chmod +x <filename>'.
