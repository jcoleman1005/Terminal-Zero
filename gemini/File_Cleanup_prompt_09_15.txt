* reorganize source directories for aesthetics
* modify application behavior

First audit the repository.

Then classify findings as:

* SAFE TO CLEAN
* SHOULD KEEP
* NEEDS HUMAN DECISION

Perform only SAFE TO CLEAN changes.

After cleanup:

* verify the Godot project still opens/parses
* run available automated/headless checks where appropriate
* verify existing standalone UI test scenes have not been broken
* inspect `git diff`
* ensure no unrelated source behavior changed

Commit the cleanup to the currently checked-out `Godot_migration` branch with a clear repository-hygiene commit message.

At completion, report:

1. What you found
2. What you changed
3. What you deliberately left alone
4. Anything requiring my decision
5. Files changed

This is a hygiene pass, not a refactor. Prefer a slightly messy working repository over risking functional code.
